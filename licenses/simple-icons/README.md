# Simple Icons (brand glyphs)

`components/ui/brand-icons.tsx` uses the WhatsApp, Discord and Instagram paths from
[Simple Icons](https://simpleicons.org) 16.35.0 (npm `simple-icons`), unmodified. The source SVGs are kept here.
